# Minecraft Mod: RuinedVillages

RuinedVillages is a Fabric Minecraft mod that adds abandoned houses, ruined village banks, collapsed stone buildings, treasure chests, valuable vanilla items, and a world survey map to newly explored areas.

## Install

1. Install Minecraft 26.3.
2. Install Fabric Loader 0.20.1 or newer.
3. Install Fabric API.
4. Install Java 25 or newer.
5. Place the RuinedVillages mod JAR in the world's `mods` folder.
6. Start Minecraft with the Fabric profile.

## Use

1. Create or open a world with the mod enabled.
2. Join the Overworld to receive one survey map centered on the world's spawn area.
3. Explore newly loaded chunks outside the immediate spawn area.
4. Watch for abandoned structures made from cobblestone, mossy cobblestone, dark oak, stone bricks, and gold blocks.
5. Search the structures for chests containing possible emeralds, gold ingots, diamonds, experience bottles, golden carrots, golden apples, and enchanted golden apples.
6. Continue exploring with players nearby to trigger additional site generation.
7. Generated chunk locations are stored in the world save so the same site is not processed again.
